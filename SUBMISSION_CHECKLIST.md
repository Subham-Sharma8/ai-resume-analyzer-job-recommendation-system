# Submission Checklist

## Required deliverables
- [x] Working Streamlit application
- [x] Complete source code
- [x] Job-role dataset
- [x] Skill dictionary
- [x] Sample-resume guidance
- [x] requirements.txt
- [x] README
- [x] Architecture/workflow diagram
- [x] Testing sheet
- [x] Project report
- [x] Testing and evaluation report
- [x] Viva questions and answers
- [x] Dockerfile (optional deployment support)

## Before final submission
1. Run `pip install -r requirements.txt`.
2. Run `pytest`.
3. Run `streamlit run app.py`.
4. Test at least one PDF and one DOCX resume.
5. Take screenshots of the dashboard and outputs for the demonstration.
6. Replace sample/test content with anonymized academic test resumes if required.
7. Push the project to GitHub.
8. Record a short demonstration video showing upload -> extraction -> recommendations -> target role -> skill gaps -> roadmap -> report download.
