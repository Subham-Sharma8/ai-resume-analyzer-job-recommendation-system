# Sample Resumes

These three DOCX files are fictional academic test resumes created specifically for testing the project.

- `Resume_A_Data_Analyst.docx` — designed to exercise the Data Analyst recommendation.
- `Resume_B_ML_Engineer.docx` — designed to exercise the Machine Learning Engineer recommendation.
- `Resume_C_NLP_Engineer.docx` — designed to exercise the NLP Engineer recommendation.

All three documents intentionally contain no real personal information. They contain no real names, phone numbers, email addresses, home addresses, photographs, ages, gender, nationality or government identifiers.

Recommended demonstration:
1. Upload Resume A and show the detected skills and role recommendations.
2. Upload Resume B and show the ML Engineer-related results.
3. Upload Resume C and show the NLP Engineer-related results.
